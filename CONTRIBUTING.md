# Contributing to DAA Laboratory (01AI0506)

Thank you for your interest in contributing to the **Design and Analysis of Algorithms (DAA) Laboratory** repository for Marwadi University!

## Code Standards
- **Standard**: C++17 (`-std=c++17`)
- **Formatting**: Google C++ Style / Clean Allman or K&R indentation with 4 spaces.
- **Documentation**: Every algorithm implementation must include standard time and space complexity annotations and dynamic execution timing output.

## Workflow
1. Fork the repository.
2. Create a topic branch (`git checkout -b feature/practical-enhancement`).
3. Ensure code compiles clean with `g++ -std=c++17 -Wall -Wextra -O2`.
4. Run sample tests and update `Sample_Output.txt`.
5. Submit a Pull Request with description of changes.
