# Applications - Practical 02

1. **Linear Search**:
   - Small arrays (\(n < 20\)).
   - Unsorted data streams where sorting overhead exceeds searching time.
   - Searching in singly linked lists where random indexing is not available.

2. **Binary Search**:
   - Database B-Trees and indexing lookups.
   - Standard C++ STL functions (`std::binary_search`, `std::lower_bound`, `std::upper_bound`).
   - Monotonic function root finding (Binary Search on Answer).
