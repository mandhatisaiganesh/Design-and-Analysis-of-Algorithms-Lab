# Practical 03: Implementation of Max Heap Sort

## 📌 Aim
To implement and analyze **Max Heap Sort** using binary max-heap data structures in C++17.

## 🎯 Objectives
1. Understand the Max-Heap property: \(A[\text{parent}(i)] \ge A[i]\).
2. Implement `heapify()` in \(\mathcal{O}(\log n)\) and `buildMaxHeap()` in \(\mathcal{O}(n)\).
3. Perform in-place sorting in \(\mathcal{O}(n \log n)\) guaranteed time.

## 📊 Complexity Summary
- **Best Case Time**: \(\mathcal{O}(n \log n)\)
- **Average Case Time**: \(\mathcal{O}(n \log n)\)
- **Worst Case Time**: \(\mathcal{O}(n \log n)\)
- **Auxiliary Space**: \(\mathcal{O}(1)\) (In-place)
